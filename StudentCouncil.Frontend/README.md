# StudentCouncil.Frontend

React-приложение платформы студсовета.

## Технологии

- React 19
- Vite
- React Router
- Chart.js + react-chartjs-2
- Font Awesome

## Структура
```
src/
├── api.js # API-клиент
├── App.jsx # Корневой компонент, роутинг
├── components/ # Переиспользуемые компоненты
├── context/ # AuthContext
├── css/ # Стили
├── pages/ # Страницы
```
