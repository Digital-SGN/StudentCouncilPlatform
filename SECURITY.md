# Политика безопасности

## Поддерживаемые версии
Обновления безопасности выпускаются только для актуальной версии из ветки `main` (развёрнутой на [studsovetsgn.ru](https://studsovetsgn.ru)).

## Сообщение об уязвимости
Если вы обнаружили уязвимость в работе платформы (ошибки авторизации, утечку данных, XSS, проблемы с правами доступа и т. д.), **пожалуйста, не создавайте публичный Issue**.

Вместо этого свяжитесь с командой разработки напрямую:
* **Telegram:** `@skebob_gg`
* **Email:** `info@studsovetsgn.ru`

### Что указать в обращении
1. Суть проблемы и потенциальное влияние.
2. Пошаговую инструкцию для воспроизведения (или скриншоты/примеры запросов).
